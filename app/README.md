# Autonomous Waypoint-Following Aircraft Simulator

Goal:
Build a software simulation where an aircraft can automatically navigate through a list of waypoints.

Learning Goals:
- How JSBSim works
- How aircraft controls are represented
- How waypoint navigation works
- Basic control systems / PID

# Tech Stack
C
GNC/control algorithms
Compile the C code as a shared library and call it from Python using ctypes or cffi.

Python
JSBSim integration, orchestration, data processing

FastAPI
API layer

PostgreSQL, Docker
Simulation scenarios and results
